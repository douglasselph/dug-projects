# Cultivation Main Expert Crossplay

This experiment is the first direct expert-vs-expert test of the fresh 2p/3p/4p Cultivation Main candidates.

It deliberately holds every other decision family at Human Baseline so that the experiment asks one narrow question:

> Do the Cultivation Main strategies that beat Human Baseline remain superior when they face other learned Cultivation Main strategies?

The experiment uses all combinations with replacement among learners 1–5 at each player count. Strategy-to-seat assignment rotates every sample.

Default overnight scale:

- 2p: 15 lineups × 4,000 games
- 3p: 35 lineups × 2,500 games
- 4p: 70 lineups × 1,500 games

Total: 252,500 games.

This is a cross-play screen, not yet adaptive counter-training. If one learner remains broadly superior across expert lineups, that learner becomes the target for the next counter-training experiment.
